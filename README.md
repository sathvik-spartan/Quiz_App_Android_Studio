# Quiz App - Android Studio

A simple and interactive **Quiz App** built using **Android Studio** and **Java**. This application lets users answer multiple-choice questions and provides instant feedback on their performance.

## Features

- Multiple-choice questions
- Score tracking
- Question navigation
- User-friendly interface
- Result summary at the end

## Tech Stack

- **Language**: Java  
- **IDE**: Android Studio  
- **UI**: XML Layouts  
- **Architecture**: Activity-based Navigation

## Getting Started

### Prerequisites

- Android Studio installed
- Java Development Kit (JDK)
- Android Emulator or physical device
